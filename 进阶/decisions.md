# 决策时间线

- **决定一：定位方案的选择**
  - 依据：`page_words.json` 是散落的词，没有直接映射。
  - 其他选择：让模型自己猜页码（不可靠）。
  - 执行证据：使用 Python 将同页词拼接，去除了标点和大小写干扰，进行滑动匹配。
  - 最终判断：该方案在 `results_adv.csv` 中获得了高 `valid` 率，证明有效。

- **决定二：改进模式的设计**
  - 依据：基础题研究了顺序影响。
  - 其他选择：让模型输出两次再投票。
  - 执行证据：在代码中设置了 `random.seed(42)` 打乱章节。
  - 最终判断：AI 辅助了代码编写，但具体打乱逻辑由本人核验，验证了长文本的抗干扰能力。

- **决定三：判分口径**
  - 将 `insufficient` 且无证据对应的定位状态设为 `absent`，不作为错误记录，视为正确拒答。
