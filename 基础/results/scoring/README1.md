# 判分规则与依据

1. **自动判分**：通过 `auto_score.py` 自动解析每次 API 调用的 JSON 响应，提取 `answer` 字段。若回答包含标准答案（如 T06 的 "25%"，T04 的 "流程乙"），则判定为 `1`（正确）；若回答“证据不足”或错误数值，判定为 `0`（错误）。
2. **标准答案获取**：开发题 D01-D04 参考了 `dev_answers.json`。评测题 T01-T08 采用人工阅读 `cases.json` 中的规则段与数据段，经过逻辑计算后确立 Ground Truth。
3. **人工调整**：自动判分完成后，人工核对了 T05（关于焦耳数）和 T06（关于技术失败率）等易错题。核实了 T05 属于“证据不足”的正确拒答，T06 的 K 条件因为截断了规则段落导致模型算错。具体分析已在 `diagnosis.md` 中详细说明。
