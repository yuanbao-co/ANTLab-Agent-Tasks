# 进阶A题：研究机制迁移报告

## 1. 完成概览
本报告基于基础题的实验框架，将“全文输入与顺序扰动（R0/R1/R2）”与“简单检索（K）”的方法，迁移到了真实的 PDF 论文（P1, P2）上。共计完成 3 道开发题与 7 道评测题的基线（baseline）与改进（improved）模式测试，总计 20 次真实 API 主任务输出。

## 2. 阅读到命题
原论文探讨了长上下文模型在信息位置不同时的表现。本题要求我们将视角转移到真实文档的“证据组织”与“原文定位”上。我们需判断指定资料是否支持某个 Claim，并定位物理页。

## 3. 实验设计
- **基线（baseline）**：按原本的章节结构，将全文喂给模型。
- **改进（improved）**：固定随机种子打乱章节顺序，测试位置扰动对模型判断的影响。
- **定位机制**：模型输出严格的 JSON，提取 `evidence_text` 后，在 `page_words.json` 中进行聚合与词级模糊匹配，寻找物理页码。

## 4. 实现与复现
代码位于 `run_adv.py`。模型输出包含 `support_status` (supported/contradicted/insufficient) 和 `evidence_text`。查页函数将同一页的单词合并并清理标点，通过前 8/6/4 个词的滑动匹配定位。

## 5. 结果与诊断
详见 `results_adv.csv`。
- **定位有效性**：所有输出支持或矛盾证据的题目，均成功映射到 `page`（`locator: valid`）。
- **位置影响**：在打乱章节顺序（improved）后，如 AD01 的结论依然是 `contradicted`，耗时从 3404ms 增加到 3793ms。说明打乱顺序增加了模型处理上下文的负担，但对强语义特征的判断未产生干扰。
- **拒答情况**：AT01、AT05、AT07 等题在基线和改进下均输出 `insufficient`，体现了模型在“证据不足”时的保守性。

## 6. 决定与未来
通过本次实验发现，非结构化的全量输入在真实 PDF 中能够工作，但代价是耗时的增加。未来的系统应该进一步优化定位机制，例如引入带 Bbox 坐标的高亮展示，提升阅读交互体验。
